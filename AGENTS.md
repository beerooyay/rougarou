# project workflow

- `shared/routes.json` is the canonical route and physics data. run `python3 shared/sync.py` after editing it, before either engine's checks or builds.
- launch the godot prototype with `godot --path godot`; verify with `godot --headless --path godot --script res://check.gd`.
- the unity project is `unity/` and uses unity 6000.3.27f1, input system 1.20.1, and urp 17.3.0. open `unity/Assets/main.unity` and press play, or run the packaged `builds/rougarou-unity.app`.
- run unity's editor checks with `unity -batchmode -nographics -quit -projectPath unity -executeMethod Check.Run -logFile unity-check.log`, substituting the installed editor executable if `unity` is not on the path. rebuild the mac app by changing `Check.Run` to `Check.Build`.
- the shared simulation runs at 60 hz. the first bakeoff climber is a physical torso with four spring contacts and procedural visual limbs, not a full articulated character. use `shared/results.json` for the validated decision and known gaps.
- the unreal project is `unreal/` (engine 5.8, c++ module `Rougarou`). it is now the main build and the source of truth for climbing rules. the model lives in `unreal/Source/Rougarou/ClimbSim.*`; unity (`unity/Assets/Main.cs`) is the original spec and lacks the later mechanics: free reaching with shoulder reach, core tension, reach-driven hips, forearm pump, and match-the-top finishes.
- verify unreal headlessly with `"/Users/Shared/Epic Games/UE_5.8/Engine/Binaries/Mac/UnrealEditor.app/Contents/MacOS/UnrealEditor" unreal/Rougarou.uproject -ExecCmds="Automation RunTests Rougarou; Quit" -unattended -nullrhi -log`. see `unreal/PLAN.md` for the roadmap.
- in unreal, `shared/routes.json` only supplies physics constants; the boulder problems are set on the gym's own panels in `unreal/Source/Rougarou/GymActor.cpp` (`WallSections`, `Problems`). problems run up stacks of flat angled panels (`FClimbPanel`), and `Rougarou.ClimbSim` must prove every one can be sent. launch with `-route=N` to start on a problem and `-shot` to save `unreal/Saved/gym.png` and `shot.png` and quit.
- `web/` is a no-build three.js port of the unreal sim, gym and climber (`sim.js` mirrors `ClimbSim.cpp`, `gym.js` mirrors `GymActor.cpp` and `HoldShapes.h`, `climber.js` mirrors `ClimberActor.cpp`). change both together. `node web/check.mjs` is the web solvability check; pushing to `main` deploys `web/` to https://beerooyay.github.io/rougarou/ after that check passes. serve it locally with `python3 -m http.server 8765 --directory web`.
- climbing feel lives in `FClimbSim::Step`: limbs travel to `Tips` at human speed and only bear weight once `Latch` is set on arrival (lower when the body is moving, the deadpoint rule), the hips ease toward `Goal`, and slipping builds up in `Slips` from `Strain` over 1 instead of a fixed timer.
